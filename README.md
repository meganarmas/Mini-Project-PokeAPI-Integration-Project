# Welcome to the Pokémon API project!

To begin, please download all files in this repository. Make sure all JavaScript files are included in the download.

Use the navigation bar to go to either the search or details page. The detail page will autofill with Pokemon that were already called in the javascript file. To find a Pokemon, use the search page. Here, you can search for a Pokémon by its name.

Enjoy! And don't get to catch them all!

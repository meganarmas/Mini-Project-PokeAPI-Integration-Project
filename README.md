# Welcome to the Pokémon API project!

To begin, please download all files in this repository. Make sure all JavaScript files are included in the download.

Use the navigation bar to go to either the search or details page. The detail page will autofill with Pokemon that were already called in the JavaScript file. 

To find a specific Pokémon, use the search page. If the Pokémon is in the database, it will pop up with the approriate information.

Enjoy! And don't get to catch them all!
